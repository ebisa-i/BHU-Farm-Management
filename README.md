# BHU Farm Management System

A web-based farm management system built using the Laravel framework.

## About the Project

The BHU Farm Management System is designed to help manage farm activities, maintain records, and generate reports.

## Technologies Used

- Laravel
- PHP
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap

## Installation

1. Clone the repository.
2. Install dependencies:

   ```bash
   composer install
   ```

3. Copy `.env.example` to `.env`.
4. Configure your database settings in `.env`.
5. Generate the application key:

   ```bash
   php artisan key:generate
   ```

6. Run database migrations if required:

   ```bash
   php artisan migrate
   ```

7. Start the development server:

   ```bash
   php artisan serve
   ```
